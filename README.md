# Sravan's Professional Portfolio & Tracker

This is Sravan Kumar Meesala's personal portfolio website showcasing AI & Data Science skills, academic education, internships, and featured projects. It includes a built-in progress tracker admin panel.

## 🚀 Features

- **Personal Portfolio**: Fully responsive single-page visual profile with 3D flip card project showcases.
- **Admin Progress Tracker**: Managed workspace at `/admin.html` to keep track of job applications, internships, task deadlines, compensations, and hiring statuses.
- **Image Carousels**: Fast, auto-advancing visual sliders displaying interactive project screenshots.
